# Quick Start Guide

## For Students Setting Up the Project

### Step 1: Clone the Repository

```bash
git clone <your-repository-url>
cd PAFF-
```

### Step 2: Database Setup

1. Install MySQL 8.0
2. Create database:

```sql
CREATE DATABASE smart_campus_db;
```

3. Update credentials in `backend/src/main/resources/application.yml`

### Step 3: Start Backend

```bash
cd backend
mvn clean install
mvn spring-boot:run
```

Backend runs on: http://localhost:8080

### Step 4: Start Frontend

```bash
cd frontend
npm install
npm run dev
```

Frontend runs on: http://localhost:3000

### Step 5: Login & Test

- Open http://localhost:3000
- Login with: `user@smartcampus.com` / `user123`
- Create a booking and test the workflow

## Module B - Individual Endpoints Summary

As required, Module B implements **4+ different HTTP methods**:

| Method | Endpoint                     | Description              |
| ------ | ---------------------------- | ------------------------ |
| POST   | `/api/bookings`              | Create booking request   |
| GET    | `/api/bookings/my-bookings`  | Get user's bookings      |
| GET    | `/api/bookings`              | Get all bookings (admin) |
| GET    | `/api/bookings/{id}`         | Get booking by ID        |
| PUT    | `/api/bookings/{id}/approve` | Approve booking          |
| PUT    | `/api/bookings/{id}/reject`  | Reject booking           |
| PUT    | `/api/bookings/{id}/cancel`  | Cancel booking           |
| DELETE | `/api/bookings/{id}`         | Delete booking           |

**Methods Used:** GET ✅ | POST ✅ | PUT ✅ | DELETE ✅

## Common Issues & Solutions

### Issue: Database connection error

**Solution:** Verify MySQL is running and credentials are correct in `application.yml`

### Issue: Port 8080 already in use

**Solution:** Stop other applications using port 8080 or change port in `application.yml`

### Issue: Frontend can't connect to backend

**Solution:** Ensure backend is running on port 8080 and CORS is configured

### Issue: JWT token expired

**Solution:** Login again to get a new token
